SVG špecifikácia · Omaľovánka pre materskú školu

2 Vyfarbiteľné oblasti a dôležitosť výplne

Každá oblasť, ktorú má dieťa kliknutím vyfarbiť, musí byť samostatný element (<path>, <circle>, <ellipse>, <polygon> alebo <rect>) s týmito atribútmi:

AtribútHodnotaPrečo / Technický význam
data-regionUnikátny slug, napr. "hrib-klobuk"Identifikátor oblasti pre kód, Vue reaktivitu a ukladanie stavu.
fill"#ffffff" — bielaNikdy nepoužívať "none" ani transparentnosť. Prehliadače často neregistrujú kliknutia na elementy bez explicitnej výplne. Vedierko a štetec potrebujú plnú počiatočnú výplň.
tvar krivkyUzavretá (path končí Z / z)Inak farba „pretečie" do susednej oblasti.
strokeŽiadny, alebo zhodný s globálnym obrysomHranice oblastí kreslia globálne obrysy (viď bod 3).
Príklad správnej oblasti:
<path data-region="strom-koruna" fill="#ffffff" d="M250 100 C 180 100 130 160 130 230..."/>
Najčastejšia chyba z Canvy: Celý obrázok je jeden veľký zlúčený <path> (napr. všetky čierne čiary stromu, hríba a slnka spolu). Takto sa nedá nič vyfarbiť. Riešenie: Každú farebne odlišnú oblasť kresliť ako vlastný objekt.

Minimálna veľkosť oblasti

Najmenšia vyfarbiteľná oblasť by mala mať aspoň ~ 60×60 px v cieľovom rozlíšení (čo zodpovedá ~5% výšky plátna pri viewBox 1024). Menšie oblasti dieťa ťažko trafí prstom na tablete či mobile. Drobné detaily preto radšej dať ako zamknuté (bod 4).

3 Obrysy, uzavretosť kriviek a riadenie kliknutí

Čierne obrysy, ktoré dieťa vidí, sú samostatná vrstva nad vyfarbiteľnými oblasťami. Majú tieto vlastnosti:

AtribútHodnota
stroke"#1a1a1a" (nie #000000, nie #231f20 ako Canva exportuje)
stroke-width"4" (pri viewBox 1024). Pre tenké linky "2.5", pre hrubé akcenty "6".
stroke-linejoin"round"
stroke-linecap"round"
fill"none" ak je to len obrys
Kritické programátorské pravidlo (Pointer Events):
Keďže obrysy ležia vo vrstve nad vyfarbiteľnými plochami, kliknutie priamo na hrubú čiaru by zablokovalo zaliatie plochy pod ňou. V globálnom CSS aplikácie alebo priamo na elementoch musí byť nastavené pointer-events: none; pre všetky čisto obrysové elementy, čím kliknutie prepadne na príslušný data-region.

Uzavretosť kriviek: Každá vyfarbiteľná oblasť musí byť plne uzavretá. Kontrola: posledný príkaz v d="..." musí byť Z alebo z. Otvorené krivky spôsobia, že farba pretečie. Inkscape: vybrať path → Path → Reverse ukáže smerové šípky, hľadaj prerušenia.

4 Zamknuté detaily

Detaily, ktoré sa nemajú vyfarbovať (zreničky, fúzy, žilky listov, ozdobné vlnovky), označ atribútom data-locked="true". Aplikácia ich bude ignorovať pri kliku (v CSS im taktiež priradí pointer-events: none;) — vedierko ani štetec ich neprefarbí. 

<circle data-locked="true" cx="410" cy="440" r="25" fill="#1a1a1a"/>
<path data-locked="true" d="M 470 510 L 540 530" 
      fill="none" stroke="#1a1a1a" stroke-width="3"/>
Pravidlo: ak je element menší ako ~60×60 px alebo má za úlohu len vizuálnu dekoráciu (lúče slnka, žilky), daj mu data-locked="true".

5 Zakázané prvky a pravidlá pre skupiny

Pred odovzdaním nesmie SVG obsahovať tieto elementy ani atribúty:

❌ Vizuálne efekty

  • <linearGradient>, <radialGradient>
  • <filter> (rozmazanie, tieň…)
  • <mask> (okrem layeringového, ak treba)
  • <pattern> (textúry)
  • filter:, opacity < 1 na vyfarbiteľných oblastiach

❌ Štruktúrne nečistoty

  • <style> blok vo vnútri SVG
  • style="..." inline atribúty
  • class="cls-1" a CSS triedy
  • transform="..." na skupinách <g> alebo root <svg> (aplikuj priamo na cesty v editoroch)
  • Nepoužité <defs>, <clipPath> bloky
  • Metadata: <title>, <desc>, komentáre
Pravidlo pre tagy skupín (<g>):
Použitie tagu <g> je povolené **výhradne na logické zoskupovanie kódu** v editore (napr. zoskupenie hlavy postavičky). Tieto skupiny však nesmú niesť žiadne transformačné ani štýlové atribúty, ktoré by komplikovali spracovanie vo Vue.

6 Pomenovanie súborov, regiónov a prístupnosť

Názvy súborov a prístupnosť (Accessibility)

  • Formát: slug.svg v priečinku /public/coloring/
  • Slug: lowercase, bez diakritiky, oddelené pomlčkami
  • Náhľad: ku každému SVG aj PNG náhľad slug.thumb.png 256×256 px
  • Prístupnosť: Každý vyfarbiteľný element môže obsahovať atribút aria-label="..." s popisom (napr. aria-label="Klobúk hríba"), čo umožní aplikáciu sprístupniť aj pre zrakovo znevýhodnené deti cez čítačky obrazovky.
Príklad názvu / slugOK?
macka.svg✓ OK
sovicka-hupkalka.svg✓ OK
oko-l / oko-r✓ OK (rozlíšenie strán príponou)
Mačka.svg✗ (diakritika, veľké písmená)
obrazok 1.svg✗ (medzera, nezmyselný názov)

Slugs pre data-region

  • Rovnaké pravidlá: lowercase, bez diakritiky, pomlčky
  • Pri zložených obrázkoch používaj prefix: "hrib-klobuk", "hrib-noha", "strom-koruna", "strom-kmen"

7 Poradie vrstvenia (z-index)

SVG sa vykresľuje v poradí zhora nadol v zdrojovom kóde. Najnižšie postavený element sa vykreslí prvý (najnižšie), posledný element je úplne navrchu. Správne poradie pre omaľovánku:

  1. Pozadie — veľké pozadia (obloha, zem, voda) ako data-region
  2. Stredné objekty — postava, stromy, domčeky, mraky s data-region a fill="#ffffff"
  3. Popredie — kvety, lístie, malé objekty
  4. Obrysy — čierne čiary (samostatné <path> s stroke, bez data-region a s pointer-events: none)
  5. Zamknuté detaily — zreničky, fúzy, ozdobné prvky s data-locked="true"

8 Príklad výsledného SVG

Ukážka kompletného formátu „Sovička na konári" (v1.1):

<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 1024 1024">

  <!-- 1. Pozadie a oblasti s aria-label -->
  <rect data-region="obloha" aria-label="Obloha" x="0" y="0" width="1024" height="780" fill="#ffffff"/>
  <path data-region="telo" aria-label="Telo sovičky" d="M 512 180 C 310 180 200 360 200 580 Z" fill="#ffffff"/>
  <path data-region="brucho" aria-label="Bruško sovičky" d="M 512 410 C 380 410 330 510 330 640 Z" fill="#ffffff"/>

  <!-- 2. Oči (vonkajšie biele kruhy) -->
  <circle data-region="oko-l" aria-label="Ľavé oko" cx="410" cy="435" r="80" fill="#ffffff"/>
  <circle data-region="oko-r" aria-label="Pravé oko" cx="614" cy="435" r="80" fill="#ffffff"/>

  <!-- 3. Čierne obrysy (globálna vrstva, žiadny data-region) -->
  <path d="M 512 180 C 310 180 200 360 200 580 Z"
        fill="none" stroke="#1a1a1a" stroke-width="4"
        stroke-linejoin="round" stroke-linecap="round"/>

  <!-- 4. Zamknuté detaily (zreničky) -->
  <circle data-locked="true" cx="410" cy="440" r="25" fill="#1a1a1a"/>
  <circle data-locked="true" cx="614" cy="440" r="25" fill="#1a1a1a"/>
</svg>

9 Špeciálne tipy pre Canvu

✅ Robte takto

  • Každý objekt (hríb, strom…) kreslite ako samostatný uzavretý tvar s bielou výplňou a čiernym obrysom.
  • Používajte plné farby — žiadne gradienty.
  • Štvorcový pomer plátna 1024 × 1024 px.
  • Export: Stiahnuť → SVG (vyžaduje Canva Pro).

❌ Nerobte toto

  • Nepoužívajte „Outline" textový efekt ani tiene a žiare.
  • Zabráňte permanentnému zlučovaniu: Nespájajte čierne čiary všetkých objektov do jedného veľkého obrysu, inak oblasti nepôjde oddeliť.
  • Nepoužívajte clip-mask cez celý dizajn.

10 Postup čistenia v Inkscape + SVGO

A) Manuálne v Inkscape

  1. Otvor SVG v Inkscape.
  2. Odstráň prebytočné filtre a efekty.
  3. Pre každý objekt: Path → Object to Path, potom prípadne Path → Break apart (Ctrl+Shift+K).
  4. Ak je obrázok jeden zlúčený obrys: použi nástroj Bucket Fill (Shift+F7) — klikni do každej uzavretej oblasti, čím vznikne nový samostatný path.
  5. Otvor XML editor (Ctrl+Shift+X) a pridaj atribúty data-region="..." a prípadne aria-label="...".
  6. Detaily označ data-locked="true".
  7. Ulož ako Plain SVG.

B) SVGO skript (Optimalizovaný pre číselnú presnosť)

Konfigurák svgo.config.js upravený tak, aby čistil nánosy z Canvy, zaokrúhľoval desatinné miesta pre úsporu veľkosti, ale **striktne zachovával naše dátové atribúty**:

module.exports = {
  multipass: true,
  plugins: [
    {
      name: 'preset-default',
      params: {
        overrides: {
          mergePaths: false,        // NEZlievaj cesty vyfarbiteľných oblastí
          collapseGroups: false,    // NEzbavuj sa logických skupín <g>
          removeViewBox: false,     // Zachovaj viewBox
          cleanupIds: false,
          cleanupNumericValues: { floatPrecision: 2 }, // Zaokrúhľovanie desatinných miest
          convertPathData: { floatPrecision: 2 },      // Optimalizácia dlhých koordinátov
          removeUnknownsAndDefaults: {
            keepDataAttrs: true,    // Zachovaj data-region, data-locked
          },
        },
      },
    },
    'removeDimensions', 'removeTitle', 'removeDesc', 'removeMetadata', 'removeComments'
  ],
};

11 Checklist pred odovzdaním

Štruktúra a čistota kódu

  • viewBox="0 0 1024 1024" na root, chýba napevno nastavená šírka/výška.
  • Úplná absencia <style> blokov, inline style="..." a CSS tried (class="...").
  • Žiadne transform="..." atribúty ponechané na skupinách <g>.

Vyfarbiteľné oblasti

  • Každá vyfarbiteľná plocha má unikátny data-region="slug".
  • Všetky vyfarbiteľné plochy majú explicitnú počiatočnú výplň fill="#ffffff" (nikdy nie none).
  • Všetky vyfarbiteľné krivky sú uzavreté (path končí na Z / z).
  • Najmenšia oblasť spĺňa rozmer ≥ 60×60 px kvôli presnosti dotyku, inak je zamknutá.

Obrysy a detaily

  • Obrysy a drobnosti majú v CSS nastavené pointer-events: none; pre správny prepad kliknutia.
  • Dekoratívne drobnosti a zreničky majú atribút data-locked="true" a nemajú priradený región.
